# Вакансия — CTO / технический директор (enterprise, автоматизация финансовой функции холдингов)

**Клиент:** небольшая IT-компания, развивает сложные ИС для автоматизации финансовой функции крупнейших холдингов. Самостоятельно занимается разработкой, внедрением и поддержкой с 2023 года.

В сопроводительном письме: релевантный опыт и навыки + желаемый уровень дохода.

## Обязанности (сжато)

1. **Технологическая стратегия и архитектура** — стратегия продукта, целевая архитектура, качество, масштабируемость/отказоустойчивость/наблюдаемость, техдолг, технологии и данные, версионность и обратная совместимость, разные конфигурации заказчиков.
2. **Управление собственной командой** — структура (архитектура, backend, frontend, QA, DevOps/SRE, аналитика, поддержка внедрений), найм и оценка TL/ключевых инженеров, зоны ответственности, техразборы и архревью, инженерная культура, эффективность без микроменеджмента.
3. **Контроль разработки и поставки** — полный цикл до промышленной эксплуатации, планирование/оценка/приоритеты, прозрачность статуса, DoR/DoD, code review / автотесты / SAST, CI/CD / окружения / миграции / релизы / откат, инциденты и RCA, «готово» = пригодно к внедрению.
4. **Развёртывание и внедрение у заказчиков** — личное участие на сложных внедрениях; on-prem / private cloud / hybrid; корпоративные ограничения инфраструктуры; HA, бэкапы, DR, обновления без простоев; интеграции (ERP, учёт, банки, платёжные шлюзы, IdP, ESB, DWH); нагрузочное/интеграционное/UAT; передача в эксплуатацию; разбор критических проблем с заказчиком.
5. **Информационная безопасность** — security by design, RBAC/SSO/аудит, защита платёжных/финансовых данных и секретов, уязвимости и зависимости, ИБ-обследования заказчиков, законодательство и политики.

## Требования (сжато)

- Enterprise-системы (не только веб/стартап); управление командой с TL/архитекторами; промышленные системы с высокими требованиями к доступности/ИБ/целостности; несколько полных циклов внедрения у крупных заказчиков; распределённые системы, транзакции, интеграции, большие данные; параллельные разработки/релизы/конфигурации; личное участие в сложных проблемах.
- Стаж: от 10 лет в разработке и внедрении корпоративных систем, из них 3–5+ лет CTO / главный архитектор / руководитель крупного направления.
- Глубокие инженерные знания: HA/highload, monolith/modular/microservices, распределённые транзакции/идемпотентность/согласованность, RDBMS, очереди, API/ESB, k8s/CI/CD/IaC, observability, RPO/RTO, secure SDLC.
- Enterprise-ландшафт: закрытые контуры, HA-кластеры, корпоративные СУБД, AD/LDAP/SSO/PKI, сети/балансировка/прокси, согласование с ИТ/ИБ заказчика, обновления с откатом, разные версии у заказчиков.
- Управленческие: процессы вместо ручного контроля; бизнес → архитектура → план → критерии готовности; TCO/риски/сроки; приоритизация продукт/долг/надёжность; честные сроки; переговоры с CIO/CISO; личная ответственность.
- Предметная область: автоматизация финансовой функции крупных компаний.
