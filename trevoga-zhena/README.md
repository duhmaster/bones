# Тревожность жены — локальная база

Рабочие материалы для плана поддержки. **Только для вас** — не показывать жене (записи и списки у неё усиливают тревогу).

## Текущий фокус

- **Неделя:** 1
- **Цель недели:** _(выбрать А / Б / В в плане)_
- **Старт:** _(дата)_

## Правила работы с базой

1. Правки в план — через диалог; не менять «на ходу» без согласования.
2. Жене не давать файлы и не вести совместные списки тревог.
3. Еженедельный отчёт — короткий, только ваши цифры для отслеживания прогресса.
