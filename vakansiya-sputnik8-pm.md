# Вакансия — Sputnik8, Project Manager (delivery + people)

Sputnik8 — крупнейший сервис бронирования экскурсий по миру на русском языке. 100+ стран, 7M+ путешественников, команда 200+.

Роль: Project Manager — деливери и пипл-менеджмент.

## Направления

1. **Деливери:** спринты/груминги/дейли/ретро, роадмап, синхронизация с другими командами, прозрачность и ускорение.
2. **Пипл:** 1:1, ИПР, найм и онбординг, работа с HR BP.
3. **Крупные кросс-функциональные проекты:** планирование, синхронизация, контроль, репортинг.
4. **Процессы:** внедрение и оптимизация project management.

## Ожидания

- 2+ года PM в разработке; пипл-менеджмент; понимание разработки и архитектуры; кросс-командные проекты (2–4 команды); несколько методологий; метрики разработки.
- Плюс: 2+ команды одновременно; координация не только разработки; технический бэкграунд.

## Условия

Гибкий формат, международный продукт, техника, менторство/обучение, ДМС, офис Андреевский двор (СПб), тимбилдинг.
